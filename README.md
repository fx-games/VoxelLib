# voxellib

A self-contained, Minecraft-compatible voxel engine in Go (go-gl/gl 3.3 core,
GLFW 3.3, mathgl). It reads and writes Minecraft worlds (Anvil) and resource
packs, and renders them with Minecraft-style light, AO and fog. The repo
also has a first-person explorer demo.

    ./run.sh                    # build'n'run (needs Go 1.26 and a GL 3.3 driver)

New here? Read [ARCHITECTURE.md](ARCHITECTURE.md) for how the parts fit together.
Agents should also read [AGENTS.md](AGENTS.md).

## Packages
| package | purpose |
|---|---|
| `voxel` | Block-state registry, 16³ paletted sections, chunks, world, sky/block light BFS |
| `voxel/anvil` | NBT, region files (.mca) and a chunk codec for 1.18+, 1.13–1.17 and legacy numeric IDs |
| `voxel/mcres` | Resource packs (dirs, zips, jars, stacked), blockstates, models, animated textures (.mcmeta) |
| `voxel/mesh` | Culled/greedy mesher, smooth light and AO, cutout/translucent layers, VisGraph |
| `voxel/render` | Texture-array region-VBO renderer: occlusion and frustum culling, animated textures, fog, sky, underwater fog, item renderer |
| `voxel/collide` | AABBs and Minecraft's axis-by-axis swept collision against any `Solids` |
| `voxel/physics` | DDA block raycast |
| `voxel/engine` | Ties it together: async streaming, lighting, meshing, saving |
| `worldgen` | Generator interfaces; `worldgen/overworld` (noise terrain, caves, ores, trees) and `worldgen/flat` are examples |
| `character` | Standalone first-person controller: walk, sprint, sneak, jump, fly, swim, dive, lava |
| `items` | Dropped items (physics, bob/spin) and the one-hand pickup/swap rule |
| `items/extrude` | 2D sprite → 3D slab mesh (Minecraft-style item extrusion), pure Go |
| `items/sheet` | Automatic sprite-sheet cutter (grid cells, divider lines, label text rejection) |

## Demo
    ./run.sh                                  # world saved to saves/demo
    ./run.sh -gen flat -world ''              # flat world, memory only
    ./run.sh -world ~/Library/Application\ Support/minecraft/saves/X -readonly

Assets are generated by tools: `go run ./cmd/rpg16pack` builds `assets/rpg16pack`
from RPG16 in `~/Downloads/rpg16`. `go run ./cmd/itemsheet` cuts
`~/Downloads/Ironchests_RPG_items_pico8_transparentbg_v1.png` into `assets/items`.
run.sh does both if they're missing.

**Controls**
- WASD and the mouse move and look. Space jumps (and swims up). Shift sneaks or descends. Ctrl sprints, or dives while in water.
- LMB breaks a block, RMB places one, and 1–9 or the scroll wheel picks the block.
- Walk over an item to take it into your hand. Whatever you held drops where you stand.
- Esc releases the mouse; press it again to quit.

**Debug keys**
| key | action |
|---|---|
| F or double Space | toggle flying |
| G | toggle no-clip |
| N | day/night |
| R | respawn |
| Q | throw held item |
| F3 | frame stats to stdout |

**Debug flags**
- `-verbose` prints per-phase worst times every 0.5 s. That includes CPU work per frame up to SwapBuffers and GPU time from a timer query.
- `-autofly N` flies forward at N blocks/s (vanilla sprint-flying is about 22).
- `-vsync on|limit|off` sets frame pacing.
- `-shot file.png -shot-at TICK` saves a screenshot and quits. It never grabs the mouse.
- `-pos x,y,z`, `-look yaw,pitch`, `-hold ITEM` and `-edits` set up test scenes.
