# voxellib

A self-contained, block-state-compatible voxel engine in Go (WebGPU via
gogpu/wgpu: Metal, DX12/Vulkan; GLFW 3.3, mathgl). It reads and writes worlds in the Anvil region format and vanilla-style resource
packs, and renders them with reference-style light, AO and fog. The repo
also has a first-person explorer demo.

    ./run.sh                    # build'n'run (needs Go 1.26 and a Metal, DX12 or Vulkan GPU)

New here? Read [ARCHITECTURE.md](ARCHITECTURE.md) for how the parts fit together.
Agents should also read [AGENTS.md](AGENTS.md).

## Packages
| package | purpose |
|---|---|
| `voxel` | Block-state registry, 16³ paletted sections, chunks, world, sky/block light BFS |
| `voxel/anvil` | NBT, region files (.mca) and a chunk codec for 1.18+, 1.13–1.17 and legacy numeric IDs |
| `voxel/mcres` | Resource packs (dirs, zips, jars, stacked), blockstates, models, animated textures (.mcmeta) |
| `voxel/mesh` | Culled/greedy mesher, smooth light and AO, cutout/translucent layers, VisGraph |
| `voxel/render` | Texture-array region-VBO renderer: occlusion and frustum culling, animated textures, fog, sky, underwater fog, item renderer |
| `voxel/collide` | AABBs and the reference game's axis-by-axis swept collision against any `Solids` |
| `voxel/physics` | DDA block raycast |
| `voxel/voxelmap` | VoxelMap directories: converted pre-1.13 maps (ids.json, blocks.json, JSON models, textures, unchanged Anvil regions) |
| `voxel/engine` | Ties it together: async streaming, lighting, meshing, saving; VoxelMap worlds with delta save slots |
| `worldgen` | Generator interfaces, a by-name generator registry, cross-chunk structures; `worldgen/overworld` (noise terrain, caves, ores, trees) and `worldgen/flat` are examples |
| `app` | Game shell: native window, rebindable input, 20 Hz tick + render loop, player (break/place, reach, hand), entity registry, save slots, screen/HUD and sound hooks |
| `character` | Standalone first-person controller: walk, sprint, sneak, jump, fly, swim, dive, lava |
| `items` | Dropped items (physics, bob/spin) and the one-hand pickup/swap rule |
| `items/extrude` | 2D sprite → 3D slab mesh (vanilla-style item extrusion), pure Go |
| `model` | Format-independent animated model: bones, skinned meshes, clips (keyframe/additive Euler tracks), Animator with crossfades |
| `model/gltf` | glTF 2.0 / GLB loader: skins, node hierarchies, all animations, embedded textures |
| `importer/packfs` | Lists files in whatever was dropped: folders, zips, nested zips |
| `importer/roblox` | Roblox-style creature packs (GLB/glTF next to FBX/.blend): one model per creature, winged ones tagged "flying" |
| `importer/mcmodel` | Vanilla-style assets: Blockbench .bbmodel, Bedrock .geo.json, Bedrock/GeckoLib animations with Molang and easings, shared animation libraries, item PNGs |
| `mobs` | Ambient creature behaviour (walkers, flyers) reporting Idle/Walk/Run/Jump/Trick states |
| `items/sheet` | Automatic sprite-sheet cutter (grid cells, divider lines, label text rejection) |
| `netcode` | Own module, stdlib only: Quake 3-style UDP netchan (sequencing, fragments, piggybacked reliables), connect handshake, LAN discovery, delta-compressed snapshots |
| `mp` | LAN multiplayer game layer on netcode: authoritative 20 Hz server, client prediction, interpolated players, real-physics arrows with unlagged hit tests, block edits kept in sync |

## Demo
    ./run.sh                                  # world saved to saves/demo
    ./run.sh -gen flat -world ''              # flat world, memory only
    ./run.sh -world <world dir> -readonly
    ./run.sh -map path/to/voxelmap -pos 0,80,0 -slot saves/slot1   # walk a VoxelMap, keep your edits

Assets are generated by tools: `go run ./cmd/rpg16pack` builds `assets/rpg16pack`
from RPG16 in `~/Downloads/rpg16`. `go run ./cmd/itemsheet` cuts
`~/Downloads/Ironchests_RPG_items_pico8_transparentbg_v1.png` into `assets/items`.
run.sh does both if they're missing.

Creatures: `-pets` (default `~/Downloads/CubePetsVol2_Free_v1.0.zip`) imports a Roblox-style pack at
startup. Its license forbids redistributing the model files, so they are never copied into the repo.
`-mcassets` (default `assets/cleannrooster`, a copy of
https://github.com/memmaker/forg-cleannrooster-assets: Blockbench models, animations, item textures)
adds humanoid mobs, animated props and 128 more pickup items. `-mob-count` sets how many spawn.
Half of the `-item-count` scattered items come from the pack. Armor-only sets (every cube in an
`armor*` group, meant to be drawn over a player body) look hollow alone and are skipped. Mobs push
each other apart, and the player pushes them aside.
Debugging models: `-lineup -species NAME -anim CLIP` stands one creature per matching species
in front of you, playing CLIP (`bind` shows the rest pose).

**Multiplayer** (LAN, up to 4 players): the main menu's Multiplayer screen sets your name and skin,
lists the games found on the LAN, joins one by address and creates a game (name, seed, world
type, mode) hosted in the game itself. Modes: deathmatch; team deathmatch (Red against Blue,
joiners fill the smaller team, no friendly fire); battle royale (rounds of one life each; the
playing field is a square round all players at the start, bounded by a translucent energy wall
that kills on touch and closes in to a smaller square every 5 minutes; the last one standing
wins the round). `-host` and
`-connect HOST[:PORT]` skip the menu; `-name` and `-skin NAME` preset the choice. Skins are the
64x64 PNGs in `-skins` (default `skins/`, filled by `go run ./cmd/fetchskins`, not in git).
Everyone carries the crossbow; a head shot kills. After (re)spawning a player is protected for
3 seconds (blinking; arrows fly through). Hold Tab for the ranking (kills, deaths); it also shows
while dead. The time of day is the server's. Placed and broken blocks (and doors) sync to
everyone, late joiners included. The server uses UDP port 28960 (allow it in the firewall).

`go run ./cmd/voxserver` is the dedicated server: no window or GPU (it builds with
`CGO_ENABLED=0`), flags `-addr`, `-name`, `-seed`, `-gen overworld|flat`, `-mode dm|tdm|br`,
`-zone-interval`, `-zone-shrink`, and a console on
stdin: `status` (the ranking with health and ping), `say TEXT`, `kick SLOT|NAME`,
`time [set day|noon|night|midnight|N | add N | stop | run]`, `quit`.
`go run ./cmd/mpbot -connect HOST` adds a headless test player that walks up to you (`-shoot` to fire).

**Controls**
- WASD and the mouse move and look. Space jumps (and swims up). Shift sneaks or descends. Ctrl sprints, or dives while in water.
- LMB breaks a block, RMB places one, and 1–9 or the scroll wheel picks the block.
- Walk over an item to take it into your hand. Whatever you held drops where you stand.
- Esc releases the mouse; press it again to quit.

**Debug keys**
| key | action |
|---|---|
| F1 | help screen with all controls |
| F or double Space | toggle flying |
| G | toggle no-clip |
| N | day/night (single player) |
| R | respawn |
| Q | throw held item |
| K | preview the nearest creature's animations one by one (name in the title) |
| Tab (hold) | multiplayer ranking |
| C | take out / put away the crossbow (from an imported pack); left click shoots arrows that arc and stick; a head shot kills; humanoids you wound fight back (crossbow carriers shoot, the rest swing a sword), and you have 10 hearts |
| F2 | screenshot to `screenshots/<timestamp>.png`, plus a `.txt` with position, look and a command to restore the view |
| F3 | frame stats to stdout |

**Debug flags**
- `-verbose` prints per-phase worst times every 0.5 s. That includes CPU work per frame up to presenting the frame (GPU time is not measured).
- `-autofly N` flies forward at N blocks/s (vanilla sprint-flying is about 22).
- `-vsync on|limit|off` sets frame pacing.
- `-bench 25s` runs unfocused without grabbing the mouse, then prints the frame rate and CPU time per frame.
- `-shot file.png -shot-at TICK` saves a screenshot and quits. It never grabs the mouse.
- `-pos x,y,z`, `-look yaw,pitch`, `-hold ITEM` and `-edits` set up test scenes.
